# راهنمای بهره‌برداری — نوشتن عبارات منطقی و استفاده از توابع آماده در DSL

این مستند توضیح می‌دهد چگونه در الگوهای اسناد، **عبارت‌های منطقی** بنویسید و از **توابع آماده** برای شرط‌گذاری، محاسبه و تصمیم‌گیری استفاده کنید.

---

## 1. انواع داده 
- **Boolean (بولی)**: فقط `true` یا `false`؛ برای شرط‌ها.
- **Number (عدد)**: برای مقادیر قابل محاسبه/مقایسه (مبلغ، درصد، تعداد و ...).
- **String (رشته)**: متن؛ داخل کوتیشن `'...'` یا `"..."`.
- **Date (تاریخ)**: تاریخ با فرمت `YYYY/MM/DD` مثل `2025/12/22`.
- **Null (تهی)**: مقدار ناموجود/نامشخص: `null`.
- **List (لیست/مجموعه)**: مجموعه‌ای از آیتم‌ها که توابعی مانند `Exists` و `Sum` روی آن اجرا می‌شود.

---

## 2. نوشتن مقدارها (Literals)

- رشته: `'Tehran'` یا `"Tehran"`
- عدد: `10` یا `10.5`
- بولی: `true` یا `false`
- تاریخ: `2020/10/12`
- تهی: `null`

---

## 3. دسترسی به داده‌ها

- **فیلد ساده**: `name` ، `age` ، `BranchCode`
- **فیلد تو در تو (با نقطه)**: `person.name` ، `invoice.total` ، `x.Product`

---

## 4. عملگرهای منطقی و مقایسه‌ای

### 4.1. مقایسه‌های عددی
برای مقایسه‌ی مقادیر عددی از عملگرهای زیر استفاده کنید:

- برابر: `==`
- نابرابر: `!=`
- بزرگتر: `>`
- بزرگتر یا مساوی: `>=`
- کوچکتر: `<`
- کوچکتر یا مساوی: `<=`

نمونه:
```text
TotalOrderPrice > 100000
DiscountPercentage <= 70
age != 20
```

### 4.2. منطق شرط‌ها (ترکیب چند شرط)
برای ترکیب شرط‌ها از موارد زیر استفاده کنید:

- `and` : هر دو شرط باید درست باشند
- `or` : کافی است یکی درست باشد

نمونه:
```text
name == 'Yasser' or name == 'Rasool'
name == 'Yasser' and age == 10
```

---

## 5. عملگرهای رشته‌ای و تاریخی

### 5.1. رشته‌ای (String)
برای بررسی متن:

- `contains` : شامل بودن
- `starts with` : شروع شدن با

نمونه:
```text
CouponKey contains '2001'
name starts with 'Ali'
```

### 5.2. تاریخی (Date)
برای مقایسه تاریخ‌ها:

- `is` : برابر بودن
- `is not` : نابرابر بودن
- `before` : قبل از
- `before or equal to` : قبل از یا مساوی
- `after` : بعد از
- `after or equal to` : بعد از یا مساوی

نمونه:
```text
OrderDate after 2020/10/01
DueDate before or equal to 2025/12/29
birthDay is not 1983/10/10
```

---

## 6. محاسبات و ترکیب متن

### 6.1. عملیات عددی
عملگرهای اصلی:

- `+` ، `-` ، `*` ، `/`

نمونه:
```text
TotalOrderPrice * 0.09
```

### 6.2. ترکیب متن (Concatenation)
عملگر `+` برای چسباندن رشته‌ها نیز استفاده می‌شود:

نمونه:
```text
'18-' + BranchCode + '-' + Now().Format('yyyyMMdd')
```

---

## 7. پرانتز (برای اولویت و خوانایی)

برای جلوگیری از ابهام و افزایش خوانایی، از پرانتز استفاده کنید:

```text
(TotalOrderPrice > 100000 and CouponKey contains '2001') or IsVipCustomer == true
```

---

## 8. توابع ناشناس با `def`

در توابعی که روی لیست‌ها کار می‌کنند، برای نوشتن شرط یا فرمول روی هر آیتم از `def` استفاده کنید.

الگوها:
```text
def x => <expression>
def x, y => <expression>   (برای توابع تجمیعی مانند Aggregate)
```

نمونه:
```text
LineItems.Exists(def x => x.Product is 'special product')
Cities.Count(def x => x.name is 'Tehran')
```

---

# 9. توابع و متدهای آماده (Built-in Methods)

## 9.1. Now()
**کاربرد:** تاریخ/زمان فعلی سیستم را برمی‌گرداند.

نمونه:
```text
Now() after or equal to 2025/12/22
```

## 9.2. Format(pattern)
**کاربرد:** یک تاریخ را بر اساس الگوی داده‌شده به رشته تبدیل می‌کند.

نمونه:
```text
Now().Format('yyyyMMdd')
```

## 9.3. AddDays(n)
**کاربرد:** به یک تاریخ مشخص، `n` روز اضافه می‌کند.

نمونه:
```text
OrderDate.AddDays(1)
```

## 9.4. Exists(predicate)
**روی:** لیست/مجموعه  
**خروجی:** `true/false`  
**کاربرد:** بررسی می‌کند آیا حداقل یک آیتم در لیست شرط را برقرار می‌کند یا خیر.

نمونه:
```text
Cities.Exists(def x => x.name is 'Tehran')
LineItems.Exists(def x => x.Product is 'special product')
```

## 9.5. Count(predicate)
**روی:** لیست/مجموعه  
**خروجی:** عدد  
**کاربرد:** تعداد آیتم‌هایی که شرط را برقرار می‌کنند را برمی‌گرداند.

نمونه:
```text
Cities.Count(def x => x.name is 'Tehran')
```

## 9.6. Sum(selector)
**روی:** لیست عددی یا لیستی که از هر آیتم مقدار عددی استخراج می‌شود  
**خروجی:** عدد  
**کاربرد:** جمع مقادیر را محاسبه می‌کند.

نمونه:
```text
Grades.Sum(def x => x)
```

## 9.7. Avg(selector)
**روی:** لیست عددی  
**خروجی:** عدد  
**کاربرد:** میانگین مقادیر را محاسبه می‌کند.

نمونه:
```text
Grades.Avg(def x => x)
```

## 9.8. Min(selector) / Max(selector)
**روی:** لیست عددی  
**خروجی:** عدد  
**کاربرد:** کمترین/بیشترین مقدار را برمی‌گرداند.

نمونه:
```text
Grades.Min(def x => x)
Grades.Max(def x => x)
```

## 9.9. First()
**روی:** لیست/مجموعه  
**خروجی:** یک آیتم  
**کاربرد:** اولین آیتم موجود در لیست را برمی‌گرداند.

نمونه:
```text
Grades.First()
```

## 9.10. Single(predicate)
**روی:** لیست/مجموعه  
**خروجی:** یک آیتم  
**کاربرد:** آیتمی را که شرط را برقرار می‌کند (و انتظار می‌رود یکتا باشد) برمی‌گرداند.

نمونه:
```text
Grades.Single(def x => x > 10)
```

## 9.11. Aggregate(seed, func)
**روی:** لیست/مجموعه  
**خروجی:** مقدار تجمیع‌شده  
**کاربرد:** آیتم‌های لیست را با یک مقدار اولیه (`seed`) به‌صورت تجمعی ترکیب می‌کند.

- `seed`: مقدار اولیه (مثلاً `0` یا `'Hi:'`)
- `func`: تابع دوپارامتری `(acc, item)`  
  - پارامتر اول: مقدار تجمعی فعلی  
  - پارامتر دوم: آیتم جاری

نمونه تجمیع متنی:
```text
Cities.Aggregate('Hi:' def s, i => s + ' ' + i.name)
```

نمونه تجمیع عددی:
```text
Grades.Aggregate(0, def x, y => x + y)
```

## 9.12. Iff(condition, trueValue, falseValue)
**کاربرد:** اگر شرط درست باشد مقدار دوم، وگرنه مقدار سوم را برمی‌گرداند.

نمونه:
```text
Iff(Grades.Sum(def x => x) > 10, 'yes', 'no')
Iff(TotalOrderPrice > 100000, 20, 0)
```

## 10. نمونه‌های استاندارد پیشنهادی

### 10.1 ( شرط ترکیبی (کوپن + مبلغ + وجود آیتم خاص)
```text
CouponKey contains '2001'
and LineItems.Exists(def x => x.Product is 'special product')
and TotalOrderPrice > 100000
```

### 10.2. تولید شماره/کد سند با تاریخ روز
```text
'18-' + BranchCode + '-' + Now().Format('yyyyMMdd')
```

### 10.3. تصمیم‌گیری متنی با Iff
```text
Iff(DueDate before 2025/12/29, 'Overdue', 'Open')
```
